# Data policy

Все данные проекта полностью синтетические и детерминированы seed.

- `generated/` — локальные полные профили, не коммитятся;
- `samples/` — до 10 строк каждой таблицы для проверки структуры в GitHub;
- `manifest.json` — seed, профиль, период и row counts.

Генератор моделирует зависимости между onboarding, connection quality, повторным
использованием и paid conversion. Они демонстрируют метод, а не показатели компании.
