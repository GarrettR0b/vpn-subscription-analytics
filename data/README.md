# Данные

Все данные проекта синтетические и создаются детерминированным генератором.

- `generated/<profile>/` — полные CSV, не коммитятся в Git.
- `samples/` — небольшие обезличенные примеры для просмотра структуры.

Генератор моделирует зависимости между onboarding, использованием AI, retention и
paid conversion. Эти зависимости нужны для проверки аналитического процесса, но не
представляют показатели реальной компании.
