# Data policy

Все данные полностью синтетические и детерминированы seed.

- `generated/` — полный локальный профиль, не коммитится;
- `samples/` — до 10 строк каждой актуальной таблицы для просмотра схемы в GitHub;
- `datalens/` — воспроизводимый экспорт четырёх SQL-витрин для загрузки в DataLens;
- `manifest.json` — seed, профиль, период и row counts.

Генератор моделирует серверные факты: продажи через сайт/Telegram, загрузку ссылки в HAPP,
платежи и прокси-сессии. Сезонные веса создают неравномерный, но ограниченный приток новых
клиентов. Данные не воспроизводят показатели реальной компании.
