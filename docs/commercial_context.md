# Commercial context wording

Рекомендуемая публичная формулировка:

> Обезличенная портфолио-реконструкция аналитики подписочного VPN-сервиса, вдохновлённая
> задачей из коммерческой практики. Архитектура решения отражает реальный рабочий подход,
> но названия, данные, параметры и результаты полностью синтетические.

Синтетическим результатам нельзя приписывать реальный production impact. Достижения из
опыта работы указываются отдельно и только в разрешённом объёме.
