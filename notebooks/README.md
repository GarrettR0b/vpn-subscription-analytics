# Notebooks

`01_vpn_activation.ipynb` - выполненный анализ месячной платящей базы и 7-дневной
активации подписок через HAPP. `01_vpn_activation.html` - автономная версия.

`02_activation_experiment.ipynb` - симуляция A/B-сравнения постоплатной инструкции HAPP с uplift,
доверительным интервалом и расчётом размера выборки.

`03_retention_cohorts.ipynb` - usage retention по возрасту когорты, cohort heatmap,
M1-сегменты, выводы и рекомендации.

Notebooks входят в показательный кейс на основе реального проекта автора. Для соблюдения
конфиденциальности данные и численные результаты публичной версии воссозданы синтетически.
Размер ядра и вероятности поведения заданы
генератором; группы control/treatment назначаются по чётности индекса пользователя.
Связь активации с retention частично задана общим показателем вовлечённости.
Выводы показывают поиск точек потерь и оценку гипотез для развития подписочного бизнеса;
фактические KPI и коммерческий эффект исходного проекта не раскрываются.

Пересборка:

```powershell
python scripts/create_starter_notebook.py
python scripts/create_experiment_notebook.py
python scripts/create_retention_notebook.py
```

Python-метрики служат независимой сверкой одноимённых PostgreSQL-витрин.

`--input-dir` задаёт источник и для вступления, и для выполняемых ячеек. Путь в notebook
сохраняется относительно его выходного каталога; ядро должно запускаться из каталога
notebook. При переносе сохраните взаимное расположение notebook и данных.
`--output` и `--html-output` позволяют сохранить результаты в другой каталог.
При недостатке наблюдений в эксперименте ДИ и p-value помечаются как неоцениваемые.
